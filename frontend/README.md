# Task Tracker — Frontend

React (Vite) frontend for the Task Tracker app. See the [root README](../README.md) for full setup, environment variables, and API documentation.

## Scripts

```bash
npm run dev       # Vite dev server (proxies /api to the backend)
npm run build     # Production build
npm run lint      # ESLint
npm run preview   # Preview the production build locally
```

## Stack

React 19, React Router, TanStack Query, Zustand, React Hook Form + Zod, Axios, shadcn/ui (Radix UI + Tailwind CSS v4), Recharts, `next-themes`, `sonner`.
